# StudyBloom — Student Planner SaaS Model

A beginner-friendly student planner built with HTML, CSS, and JavaScript.

## Features
- Dashboard with task totals and completion progress
- Add tasks with optional times
- Mark tasks complete or delete them
- Filter tasks by all, to-do, and completed
- Add and remove study schedule blocks
- Saves tasks and schedule in browser Local Storage
- Responsive pastel pink and lavender layout

## Run locally
Open `index.html` in a web browser. No build tools are required.

## Publish with GitHub Pages
1. Create a repository named `student-planner-saas`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish your site.

Expected URL: `https://YOUR-USERNAME.github.io/student-planner-saas/`

## Note
This is a front-end demo, not a complete cloud SaaS product. Data is stored only in the current browser. A real multi-user SaaS version needs a backend, database, authentication, and secure hosting.

## School background
The app includes `school-background.png`, a pastel stationery flat-lay used as the page background. Keep this image in the same folder as `index.html` and `style.css` when uploading to GitHub Pages.
